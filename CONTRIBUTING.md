# Contributing

Thanks for your interest in contributing to `llmterm`.

## Development setup

1. Install Python 3.13.14 and [uv](https://docs.astral.sh/uv/).
2. Clone the repository and run `uv sync`.
3. Copy `.env.example` to `.env` if you need an API key.
4. Run the application with `uv run llmterm`.

Before opening a pull request, keep changes focused and verify that the
package builds successfully with `uv build`.
